# Вопросы для пары

Статический портал для `https://slytry.github.io/voprosy-dlya-pary/`. Ванильный JavaScript, ES-модули, без сборки и зависимостей.

## Запуск

Нужны Python 3 для локального сервера и Node.js 22+ для тестов и шифрования.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://localhost:8000/`. Открытие `index.html` через `file://` не подходит для ES-модулей и загрузки JSON.

Для GitHub Pages выбрать публикацию из корня ветки `main`. Все пути относительные; подпапка `/voprosy-dlya-pary/` поддерживается. Файл `.nojekyll` отключает обработку Jekyll. В странице указан `noindex`.

Портал и колоды кэшируются service worker после первого успешного открытия. Затем ими можно пользоваться без интернета, включая повторный запуск. Требуется HTTPS или localhost. Google Fonts необязательны: без сети используются системные шрифты. При изменении списка ресурсов service worker нужно обновить `CORE` и номер `CACHE` в `sw.js`.

## Как пользоваться

- Выбрать колоду на главной. «Разговоры вдвоём» открывается сразу; для «Расскажи» нужен пароль из `private/password.txt`.
- Смахнуть карточку влево или нажать «Следующая». Смахнуть вправо или нажать стрелку влево, чтобы вернуться. При фокусе вне полей и кнопок работают клавиши ←/→.
- Выключать темы нажатием на их названия; хотя бы одна тема остаётся включённой. Скрытые карточки исключены из счётчиков. Задания можно смешать с вопросами или брать только кнопкой «Задание».
- Звезда добавляет вопрос или задание в общее избранное. «Играть избранное» собирает карточки из всех колод. Скрытая карточка исключается и из обычной игры, и из избранного. Сразу после скрытия доступна кнопка «Вернуть»; позже вернуть можно в разделе «Скрытые».
- Под вопросом доступны ответы двух игроков. Они сохраняются при каждом вводе. Имена задаются в настройках. В разделе «Наши ответы» есть группировка по колодам и темам, даты, переход к вопросу, скачивание Markdown и копирование.

Профиль общий для всех колод. `localStorage` содержит избранное, скрытые карточки, ответы и имена; позиции, порядок игры и фильтры сохраняются отдельно на устройстве. Пароль и токен тоже хранятся локально, в незашифрованных настройках браузера. Очистка данных сайта удаляет локальные данные. Ответы можно заранее скачать или синхронизировать.

## Синхронизация через GitHub Gist

1. В настройках портала сохранить пароль от колод. На всех устройствах нужен одинаковый пароль.
2. В GitHub открыть **Settings → Developer settings → Personal access tokens**: <https://github.com/settings/tokens>.
3. Создать **fine-grained token** с **Account permissions → Gists → Read and write** либо **classic token** со scope **gist**. Доступ к репозиториям порталу не нужен.
4. Вставить токен в настройках портала и нажать «Включить синхронизацию». На другом устройстве повторить с токеном того же GitHub-аккаунта.

Портал находит secret gist с description `voprosy-dlya-pary state` и файлом `state.json` или создаёт его. Если таких gist несколько, используется первый найденный. Сам файл зашифрован AES-256-GCM с PBKDF2-SHA256, 310 000 итераций и собственной солью. Secret gist доступен по ссылке, поэтому шифрование обязательно. Токен, пароль и позиции в игре в Gist не попадают.

При запуске, возвращении на вкладку и восстановлении сети приложение читает удалённый профиль, сливает записи, затем отправляет результат. Изменения отправляются примерно через 2 секунды после последней правки. При ошибках повторяются попытки с интервалом до минуты; местные изменения сохраняются. Статус виден в настройках.

Каждая запись избранного, скрытых и ответов имеет дату `at`. Удаление оставляет tombstone `{removed:true, at}`; более поздняя запись побеждает. Равные даты разрешаются одинаково на всех устройствах, при равенстве удаление побеждает добавление. Имена сливаются одним объектом по дате. Одновременная правка одного ответа на двух устройствах сохраняет позднюю версию целиком. Отключение синхронизации стирает местный токен; Gist и локальный профиль остаются.

## Колоды и шифрование

Реестр — `decks/index.json`. Глобальный ключ карточки — `${deckId}/${id}`. ID существующих вопросов и заданий нельзя менять после начала использования: к ним привязан профиль.

Открытая колода: `decks/razgovory-vdvoyom.json` — 72 вопроса, 7 тем, 20 заданий. Купленная: `private/decks/rasskazhi.json` — 100 печатных вопросов, 3 добавленных агентом, 9 тем и 20 сгенерированных заданий. Печатные ID имеют вид `07a`/`07b`, агентские — `x1`…`x3`. В публичной папке лежит только `decks/rasskazhi.enc.json`.

```sh
node scripts/encrypt-deck.mjs rasskazhi
node --test
```

Скрипт берёт пароль из переменной `DECK_PASSWORD` либо из `private/password.txt`. JSON шифруется целиком, включая правила, фразу колоды и задания. Формат `{v:1,kdf:'PBKDF2-SHA256',iter:310000,salt,iv,data}` совместим с WebCrypto; все бинарные поля в base64, `data` включает authentication tag GCM. При каждом шифровании создаются новые соль и IV. Производные ключи браузер кэширует только в памяти сеанса.

Чтобы добавить купленную колоду:

1. Создать `private/decks/<id>.json` по формату существующей колоды: `id`, `title`, необязательные `rules`/`tagline`, `themes`, `questions`, `tasks`.
2. У темы указать `id`, `name`, `color` (hex), `suit` — имя SVG-масти из `js/suits.js`. У вопроса — стабильный `id`, `theme`, `text`, необязательные `card`/`source`. У заданий — `name`, `source:'agent'`, необязательные `color`/`suit`, `items:[{id,text}]`.
3. Выполнить `node scripts/encrypt-deck.mjs <id>`.
4. Добавить в `decks/index.json` запись с `source.kind:'purchased'`, `encrypted:true`, `file:'<id>.enc.json'`, `questionCount` и остальными метаданными по образцу.
5. Добавить проверку новой колоды в `tests/data.test.js`, выполнить `node --test`. Service worker возьмёт новую колоду из реестра при следующей установке; обновить версию `CACHE` в `sw.js`.

`private/` исключена из Git. Не переносить в публичные файлы пароль, открытый JSON, вопросы, правила или расшифровки купленных колод. `private/sources/` — неизменяемые исходники. Скрипт шифрования не создаёт промежуточных открытых файлов вне `private/`.

## Проверки

`node --test` проверяет криптографический roundtrip и совместимость с Node crypto, неверный пароль и повреждённый шифротекст, слияние и tombstones, историю игры, исключение скрытых вопросов и заданий за 120 ходов, восстановление позиций, обмен с Gist через заглушки без сети, формат данных и точность переноса источников. Проверка утечки ищет несколько длинных уникальных вопросов и пароль во всех публичных файлах.

Для полной сверки нужны `private/sources/`, открытый JSON купленной колоды и пароль. В публичном checkout тесты, которым нужны эти файлы, пропускаются с явной причиной. Проверки открытой колоды, envelope, crypto, merge, game и sync работают без них.

В браузере дополнительно проверить открытие обеих колод, неверный и верный пароль, звезду, скрытие и 120 переходов, возврат скрытого, игру избранного, журнал и экспорт, навигацию назад, темы, ширину 360 px и тёмный режим. Для проверки Pages локально запустить сервер из родительской директории и открыть `/voprosy-dlya-pary/`.
